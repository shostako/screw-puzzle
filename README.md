# ネジ外し工房（試作）

スマホで流行っているねじ外しパズル（色合わせ型）の自作。最終目標は Android アプリ。

- 試作本体: `index.html`（1ファイル。Matter.js 0.19.0 を cdnjs から、poly-decomp 0.3.0 を jsDelivr から読み込む）
- 公開版: https://claude.ai/artifact/QhdRnGorN51nNAbN9JppKJ （同じ会話か、この URL を `url` に渡して再公開すると更新される）
- GitHub Pages: https://shostako.github.io/screw-puzzle/ （master への push で自動配信。中身は `scripts/build.sh` が包んだ `dist/index.html`）

## 現在のルール

- 上に色つきの箱が2つ。ねじをタップすると、同じ色で空きのある箱に入る。3本で満杯になると消え、次の箱が出る
- 合う箱が無いねじは待機スロット（5個）へ。新しい箱が出たら、スロットの同じ色のねじは自動で移る
- 板はすべて階層に属し、同じ階層の板は同じ色（離れていても）。上の階層の板に少しでも隠れているねじは外せない（タップすると震えて拒否）
- 見えるのは、その時点の最上階層（ねじが残っている一番上の階層）から5段目までの板とねじ。それより下は板ごと見えず、触れない。最上階層の板が全部外れる（ねじ0本で落ち始める）と、見える範囲が1段下がり、新しく見えた板はふわっと現れる
- 同じ階層の板どうしはぶつかる（回った板が隣の板に当たって止まる、落ちる板が引っかかる）。違う階層どうしはすり抜ける
- 板を留めるねじが2本以上なら固定、1本になるとそのねじを軸にぶら下がり、0本で落下
- 全部の箱を埋めたらクリア。スロットが満杯で入れられるねじが無ければ詰み

## 見た目

市販アプリ（ユーザーが遊んでいるもの）のスクリーンショットを参考にしている（2026-09-27）。

- 背景は木目。起動時にノイズで描いて body の背景に貼る
- 箱は取っ手つきの工具箱。中に3つの穴を三角に並べる
- 板は半透明で彩度の高い色、太いクリーム色の縁取り。下の板やねじが透けて見える。外したねじ穴は白い輪で残る
- ねじは縁が濃い円に、立体風の十字。置いた時点では十字がほぼ正立する
- 上部は やり直しボタン／ステージ番号／外したねじの割合

## 実装メモ

- ステージはステージ番号を種にした乱数で自動生成（同じ番号なら同じ盤面）。板の形は7種類（棒、円弧〜C字、扇、しずく、円をつないだ塊、くの字、角の丸い3〜6角形）で、どれも符号付き距離関数で定義する。ねじ穴は板の縁から 20 以上内側、ねじ同士は中心間 34 以上
- 板を下の階層から置く。階層ごとに枚数（2〜4）を先に決め、形と位置を変えて最大14回まで粘って埋める（2026-09-27 修正。以前は1枚ごとに半々で次の階層へ進み、9割の階層が1枚だった）。1枚の板のねじ穴は最大5、板は最大18枚。同じ階層の板どうしは重ねず、すき間を 6 以上空ける。下の階層の板とは面積の 15〜80% が重なること、下のねじを隠しすぎないこと（ステージに応じて最大 3〜6 本）を条件にする
- 詰みにくくするため、上の層のねじほど早く出る箱の色を割り当てている。解けることの保証は無い
- 描画用の輪郭は距離関数からマーチングスクエアで取り出した多角形（Path2D）。衝突用には外周を粗く間引いて poly-decomp で凸な部品に分け、複合剛体にする。質量・重心・慣性モーメントは同じ格子から計算した実形状の値に置き直す（`Body.setCentre`）。慣性モーメントは Matter.js の既定に合わせて4倍
- 衝突の組み合わせは collisionFilter の category と mask を階層ごとのビットにして、同じ階層どうしだけにしている
- 「隠れている」の判定は、上の階層の板の距離関数をねじの中心と外周16点（半径 SR+1）で評価する
- 板が1本留めになったとき、重心が残ったねじのほぼ真上（倒立の釣り合い）なら、左右どちらかへ回転速度 0.24 rad/秒 を下支えして押し出す。0.3 rad 傾いたら押すのをやめて重力に任せる。重心が少しでもずれていればその向き、ぴったりなら向きはランダム（2026-09-27、ユーザー要望「釣り合っていても徐々に傾いてひっくり返る」）
- 到達ステージは localStorage に保存
